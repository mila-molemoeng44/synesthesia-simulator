# Why Synthetic Data
I chose to generate synthetic data because I needed problem specific data that would map a state or feeling to features of sound. 
The creation of this model was done with an LLM and it was quick and cost-effective to generate. 
The size of the csv file is quite small too (as most csv files are).

# Limitations of Data
With this data being synthetic, it isn't a true model of synesthesia. I cannot confidently state that it closely models it either.
What I can say is that this synthetic data models a state coordinated by different features of sound that all influence the related state.
There was some manipulation done on the raw collected data, multiplying it by multiples of 10 as some of the raw data was incredibly small and all the predictions pointed to the second class.
